# Anpu’s Feather — iOS

The native iOS app. A [Capacitor](https://capacitorjs.com) wrapper that runs
the [web experience](../web/) full-screen in a WKWebView, so the iOS app and
the browser game are always the same game.

## Requirements

- **macOS** with **Xcode** (the native build tools are Apple-only)
- **CocoaPods** — `sudo gem install cocoapods` (or `brew install cocoapods`)
- Node.js (for the Capacitor CLI and to build the web app)

> The generated Xcode project is committed, but `pod install` and the Xcode
> build only run on a Mac. On Linux/CI, `cap sync` copies the web assets and
> skips those steps.

## Build & run

```sh
npm install       # Capacitor CLI + iOS platform
npm run sync      # build apps/web and copy its dist into the iOS project
npm run open      # open ios/App/App.xcworkspace in Xcode
```

Then in Xcode pick a simulator or device and press **Run**.

`npm run sync` is the command to re-run whenever the web app changes — it
rebuilds `apps/web` and refreshes the bundled copy inside the native project.

## Layout

- `capacitor.config.json` — app id, name, and `webDir` (points at `../web/dist`)
- `ios/` — the generated native Xcode project
  - `ios/App/App.xcworkspace` — open **this** in Xcode
  - `ios/App/App/public/` — the synced web build (git-ignored; regenerated by `cap sync`)
  - `ios/App/App/Info.plist` — status bar hidden for the full-bleed black experience; landscape + portrait supported

## Configuration notes

- **App ID:** `co.haam.anpusfeather` — change it in `capacitor.config.json`
  to your own bundle identifier before submitting to the App Store.
- **Signing:** set your Apple Developer team in Xcode → Signing & Capabilities.
- **Saving the wisdom card:** on iOS the card is handed to the native share
  sheet (via the Web Share API), so it can be saved to Photos or shared.
